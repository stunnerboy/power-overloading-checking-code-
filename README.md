# power-overloading-checking-code-
in this repository, i had written the code to check how much power overloaded, and the power trips when overload occurs. 


# components used :

1. Arduino UNO
2. lcd 16x2
3. ACS712 current sensor
4. ZMPT102 voltage sensor
5. 5v 10A relay
6. 4 bulb holders
7. a 2-pin plug
8. a 12v AC-DC Adaptor
